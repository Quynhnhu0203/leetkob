# Queue Using Two Stacks

Implement a First-In-First-Out (FIFO) queue using two stacks.

## Operations
- `1 x`: Enqueue integer `x` into the queue.
- `2`: Dequeue an element from the queue and print it.

## Input Format
The first line contains an integer `q`, the number of operations.
The following `q` lines contain the operations.

## Output Format
For each dequeue operation (`2`), print the dequeued integer on a new line.
